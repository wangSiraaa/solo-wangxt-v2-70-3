# 岩芯 CT 体数据浏览器（corect-viewer）

纯浏览器端的地质岩芯 CT 体数据浏览工具：扫描资料**不出本机**，无需任何服务器处理。

- **React + TypeScript + vtk.js**：三个正交切面（水平面 K / 矢状面 I / 冠状面 J）联动显示
- **双体积并排对比**：基准（A）与对比（B）两份 `.corevol` 同屏并排，按物理坐标同步十字丝
- **Web Worker** 解码项目约定的 `.corevol` 体素格式 + 双体积灰度取样，主线程不卡顿
- **IndexedDB** 保存工程（原始体数据文件）、标注（测量、ROI、十字丝位置）与对比会话（映射参数、双体积身份、视图状态），刷新页面后完整恢复
- 距离测量按**体素物理间距**（各向异性）计算，对比模式下两侧各自使用自己的间距
- 矩形 ROI 框选：体素计数 + 阈值预览（掩膜高亮 + 统计）

## 快速开始

```bash
npm install
npm run sample   # 重新生成合成岩芯样例（可选，已随仓库生成）
npm run dev      # 开发服务器
npm run test     # 单元测试 + 合成岩芯验收测试
npm run build    # 生产构建
```

打开页面后点击「加载样例」。首版仅支持随项目提供的小体积样例（体素总数 ≤ 6400 万）。

## 双体积并排对比

在已加载基准体积（A）后，通过侧栏「双体积对比」加载对比体积（B，样例 / 导入 / 工程列表均可）：

- **物理坐标同步**：任一侧拖动十字丝，另一侧按共享物理坐标定位；
  共享坐标 = 各自体积物理坐标经**原点偏移**（mm）与**轴向翻转**（i → dims−1−i）映射后的位置
- **越界处理**：目标侧超出物理范围时保持最近有效位置（逐轴夹取），
  视图角标与状态栏显式提示「越界·已夹取」；真源是共享物理坐标，单向推导，不会回写循环
- **窗宽窗位**：两侧独立调节；勾选「锁定两侧窗宽窗位联动」后同步（启用时以 A 为准对齐）
- **测距**：测量标注记录所属侧与间距快照，A/B 各自按自己的体素间距计算 mm
- **灰度差值**：状态栏实时显示同一物理位置两侧灰度（值 A / 值 B / Δ=A−B）；
  取样在 Web Worker 中进行，请求带单调 id，过期响应直接丢弃——快速拖动时只显示最后位置的结果
- **会话持久化**：映射参数、双体积身份（SHA-256 内容哈希）、共享物理光标、窗宽窗位与联动锁
  存入 IndexedDB（`compareSessions`）。刷新后两份文件身份一致则完整恢复；
  **任一文件内容改变**则旧映射自动停用（重置为恒等映射），需检查映射后点「确认当前映射」重新启用

## `.corevol` 文件格式（v1，小端序）

| 偏移 | 大小 | 类型 | 字段 |
|---|---|---|---|
| 0 | 8 | char[8] | 魔数 `"COREVOL\0"` |
| 8 | 2 | u16 | 格式版本 = 1 |
| 10 | 2 | u16 | 数值类型：0=uint8 1=int8 2=uint16 3=int16 4=uint32 5=int32 6=float32 7=float64 |
| 12 | 4 | u32 | headerSize：文件头总字节数（体素数据起始偏移，须为 8 的倍数） |
| 16 | 12 | 3×u32 | dims = [I, J, K] 体素维度 |
| 28 | 24 | 3×f64 | spacing = [sx, sy, sz] 体素物理间距（mm） |
| 52 | 24 | 3×f64 | origin = [ox, oy, oz] 物理原点（mm） |
| 76 | 2 | u16 | 工程名 UTF-8 字节数 N |
| 78 | N | char | 工程名（UTF-8） |
| … | | | 零填充至 headerSize |
| headerSize | … | | 体素数据，**I 方向变化最快**（x 最快、z 最慢），行主序 |

解码器（`src/format/corevol.ts`，在 Web Worker 中运行）校验：魔数、版本、数值类型、
headerSize 对齐、维度合法且 ≤ 上限、间距为正有限数、文件总字节数精确匹配。

## 合成岩芯样例与验证清单

`public/samples/synthetic-core.corevol`（128×128×200，uint8，**各向异性**间距 0.5×0.5×2.0 mm），
由 `scripts/generate-sample.mjs` 生成。内置已知几何标志，用于验证坐标与测量：

| 验证项 | 标志 | 期望值 |
|---|---|---|
| 坐标换算 | 高亮立方体中心 IJK = (100, 30, 12) | 状态栏物理坐标 = (50.00, 15.00, 24.00) mm |
| 坐标一致性 | 十字丝移到 (100, 30, 12) | 三个切面同时显示立方体截面（5×5 亮块） |
| 距离测量 | 标志点 A=(24,24,60)、B=(84,104,120)（亮球） | 测量距离 = **130.00 mm**（体素差 (60,80,60) × 间距 = 物理差 (30,40,120)） |
| 各向异性 | K 方向滚轮换一层 | 状态栏物理 Z 变化 2.00 mm；I/J 方向 1 体素 = 0.50 mm |
| ROI 统计 | K=12 层框选立方体截面 [98..102]×[28..32] | 体素总数 = 25，阈值 ≥200 计数 = 25，均值 = 255 |
| 持久化 | 添加测量/ROI 后刷新页面 | 标注、十字丝位置完整恢复 |

以上全部有自动化测试覆盖（`src/format/sample.test.ts` 等，共 47 例）。

## 对比样例 B 与双体验收清单

`public/samples/synthetic-core-b.corevol`（128×128×100，uint8，间距 0.5×0.5×4.0 mm），
层理沿 K 翻转（物理周期与 A 相同），灰度整体偏移 +20。验收项（均有自动化覆盖）：

| 验证项 | 场景 | 期望值 |
|---|---|---|
| 物理同步 | A 间距 0.5×0.5×2.0 vs B 间距 0.5×0.5×4.0，物理范围相同 | A(10,20,30) ↔ B(10,20,15)（z=60mm） |
| 翻转端点 | B 开启「翻转 K」 | A k=0 ↔ B k=99，A k=198 ↔ B k=0 |
| 越界稳定 | A k=199（z=398mm）超出 B 范围（396mm） | B 夹取 k=99 并提示，A 不动、重复输入幂等 |
| 快速拖动 | 同步连发 41 次十字丝移动 | 状态栏只显示最后位置的取样值与 Δ |
| 会话恢复 | 设置翻转映射 + 联动锁后刷新 | 映射、光标（B k=84）、联动锁完整恢复 |
| 身份校验 | 改写 B 文件一个字节后刷新 | 旧映射停用（恒等重置），确认后恢复可用 |

## 操作说明

- **浏览工具**：拖动定位十字丝（三视图同步）；滚轮在该视图换层
- **测量工具**：依次点击两点（可跨不同视图点击），生成距离标注（mm）
- **框选 ROI**：在某层拖出矩形，侧栏显示体素总数、≥阈值数量、min/max/均值；
  调节阈值滑块时当前层以红色掩膜预览 ≥ 阈值的体素
- 侧栏可切换/删除工程、调窗宽窗位、管理标注列表

## 数据持久化

- `projects` 对象仓库：原始 `.corevol` 文件（刷新后重新解码恢复体数据）
- `annotations` 对象仓库：测量、ROI、十字丝位置（变更后 300ms 防抖写入）
- `compareSessions` 对象仓库：双体积对比会话（映射参数、两侧文件 SHA-256、共享物理光标、
  双侧窗宽窗位、联动锁；变更后 300ms 防抖写入，映射待确认期间不覆盖旧会话）
- `localStorage` 记录最后打开的工程 id，启动时自动恢复

## 目录结构

```
src/
  format/corevol.ts        # 格式定义 + 编解码纯函数
  workers/                 # Web Worker：解码（含内容哈希）、双体积灰度取样（过期响应丢弃）
  geometry/viewMath.ts     # IJK↔物理坐标、切面相机模型、屏幕映射、测距
  geometry/compareMath.ts  # 双体积映射（翻转+偏移）、物理同步、越界夹取（纯函数）
  geometry/roi.ts          # ROI 统计（体素计数 / 阈值预览）
  db/projectDb.ts          # IndexedDB（idb 封装，含对比会话仓库）
  state/store.ts           # zustand 全局状态 + 持久化订阅
  components/SliceView.tsx # 正交切面视图（vtk.js 渲染 + Canvas 叠加交互，A/B 双侧复用）
  components/CompareSection.tsx # 对比控制（映射编辑、联动锁、确认）
scripts/generate-sample.mjs # 合成岩芯样例生成器（A + 对比样例 B）
```
