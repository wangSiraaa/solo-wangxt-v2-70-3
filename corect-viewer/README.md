# 岩芯 CT 体数据浏览器（corect-viewer）

纯浏览器端的地质岩芯 CT 体数据浏览工具：扫描资料**不出本机**，无需任何服务器处理。

- **React + TypeScript + vtk.js**：三个正交切面（水平面 K / 矢状面 I / 冠状面 J）联动显示
- **双体积并排同步比较**：基准/对比两份 `.corevol` 同时打开，经公共物理空间同步十字丝；
  支持逐轴原点偏移与翻转映射、独立/锁定窗宽窗位、同物理位置灰度差值探针
- **Web Worker** 解码项目约定的 `.corevol` 体素格式，并承担大体积差值取样，主线程不卡顿
- **IndexedDB** 保存工程（原始体数据文件）、标注（测量、ROI、十字丝位置）与比较会话
  （映射参数、双体积内容指纹、视图状态），刷新页面后完整恢复；文件内容变化时旧映射自动停用
- 距离测量按**体素物理间距**（各向异性）计算，双体积模式下分别使用各自间距
- 矩形 ROI 框选：体素计数 + 阈值预览（掩膜高亮 + 统计）

## 快速开始

```bash
npm install
npm run sample   # 重新生成合成岩芯样例（可选，已随仓库生成）
npm run dev      # 开发服务器
npm run test     # 单元测试 + 合成岩芯验收测试
npm run build    # 生产构建
```

打开页面后点击「加载样例」。首版仅支持随项目提供的小体积样例（体素总数 ≤ 6400 万）。

## `.corevol` 文件格式（v1，小端序）

| 偏移 | 大小 | 类型 | 字段 |
|---|---|---|---|
| 0 | 8 | char[8] | 魔数 `"COREVOL\0"` |
| 8 | 2 | u16 | 格式版本 = 1 |
| 10 | 2 | u16 | 数值类型：0=uint8 1=int8 2=uint16 3=int16 4=uint32 5=int32 6=float32 7=float64 |
| 12 | 4 | u32 | headerSize：文件头总字节数（体素数据起始偏移，须为 8 的倍数） |
| 16 | 12 | 3×u32 | dims = [I, J, K] 体素维度 |
| 28 | 24 | 3×f64 | spacing = [sx, sy, sz] 体素物理间距（mm） |
| 52 | 24 | 3×f64 | origin = [ox, oy, oz] 物理原点（mm） |
| 76 | 2 | u16 | 工程名 UTF-8 字节数 N |
| 78 | N | char | 工程名（UTF-8） |
| … | | | 零填充至 headerSize |
| headerSize | … | | 体素数据，**I 方向变化最快**（x 最快、z 最慢），行主序 |

解码器（`src/format/corevol.ts`，在 Web Worker 中运行）校验：魔数、版本、数值类型、
headerSize 对齐、维度合法且 ≤ 上限、间距为正有限数、文件总字节数精确匹配。

## 双体积并排同步比较

侧栏「双体积比较」选择两份工程后进入：两侧各三个正交切面并排显示。

- **同步模型**：每侧有独立映射 `common = offset + (flip ? lo+hi−phys : phys)`，
  其中 phys 是本侧体素物理坐标、[lo,hi] 是本侧该轴物理范围。任一侧移动十字丝，
  另一侧经公共物理空间换算定位；**单向写入不回流**，越界时另一侧夹取到最近有效体素并显式提示，
  不会产生跳动循环。
- **映射编辑**：每侧可设 ΔI/ΔJ/ΔK 原点偏移（mm）并逐轴翻转；翻转时绕本侧物理范围中心镜像，
  端点准确互换。用户调整映射即视为重新确认。
- **窗宽窗位**：默认两侧独立，可勾选「锁定联动」（锁定瞬间以活动侧为准对齐）。
- **测距 / ROI**：标注按侧归属，距离分别使用该侧的体素间距；测量不跨体积（换侧点击重落第一点）。
- **灰度差值探针**：以活动侧十字丝的公共物理位置为中心做 ±5mm、9³ 邻域取样，
  在 **Web Worker**（`diffSample.worker.ts`，双侧体数据零拷贝常驻）中运行；
  请求带单调递增 id，过期响应在客户端被丢弃——快速拖动时只显示最后位置的差值。
- **持久化**：会话（映射、双侧文件 SHA-256 指纹、双侧十字丝/窗宽窗位/锁定状态）存入
  IndexedDB `compareSessions` 仓库。刷新时重算两份文件指纹：身份一致才恢复并启用映射；
  任一文件内容变化 → 旧映射停用、显示横幅并要求重新确认。

### 比较样例对与验收

`npm run sample` 额外生成 `public/samples/compare-{a,b}.corevol`：
物理范围同为 32×32×80 mm，A 间距 1×1×2 mm（33×33×41），B 间距 0.5×0.5×1 mm（65×65×81，
含仅 B 可见的 +80「病灶」球），用于验证：

- 间距不同但物理范围相同 → 同步索引恒为 2 倍关系
- 翻转轴后端点对应、原点偏移换算
- 一侧越界不产生跳动循环
- 病灶处 Δ ≈ −80；快速拖动后差值停在最后位置
- 测距分别为 10.00 mm 与 5.00 mm（同样 10 个体素）
- 刷新恢复会话；篡改任一份文件后旧映射停用、重新确认后恢复

## 操作说明

- **浏览工具**：拖动定位十字丝（三视图同步）；滚轮在该视图换层
- **双体积比较**：侧栏选择基准与对比工程 →「进入比较」；在映射编辑器调偏移/翻转，
  十字丝按物理坐标联动；差值探针显示同位置双侧灰度差与邻域统计
- **测量工具**：依次点击两点（可跨不同视图点击），生成距离标注（mm）；比较模式下标注按侧分开
- **框选 ROI**：在某层拖出矩形，侧栏显示体素总数、≥阈值数量、min/max/均值；
  调节阈值滑块时当前层以红色掩膜预览 ≥ 阈值的体素
- 侧栏可切换/删除工程、调窗宽窗位（可锁定双侧联动）、管理标注列表

## 数据持久化

- `projects` 对象仓库：原始 `.corevol` 文件（刷新后重新解码恢复体数据）
- `annotations` 对象仓库：测量、ROI、十字丝位置（变更后 300ms 防抖写入）
- `compareSessions` 对象仓库：双体积比较会话——映射参数、双侧文件 SHA-256 指纹、视图状态
- `localStorage` 记录最后打开的模式（单体积/比较）、工程 id 与比较会话 id，启动时自动恢复

## 目录结构

```
src/
  format/corevol.ts        # 格式定义 + 编解码纯函数
  format/fileHash.ts       # 文件内容 SHA-256 指纹（会话身份校验）
  workers/                 # Web Worker 解码 / 差值取样及主线程封装
  geometry/viewMath.ts     # IJK↔物理坐标、切面相机模型、屏幕映射、测距
  geometry/syncMap.ts      # 公共物理空间映射（偏移 + 逐轴翻转 + 越界夹取）
  geometry/diffSample.ts   # 双侧灰度差值邻域取样（Worker 内运行的纯函数）
  geometry/roi.ts          # ROI 统计（体素计数 / 阈值预览）
  db/projectDb.ts          # IndexedDB（idb 封装）
  state/store.ts           # zustand 全局状态（双侧同步/持久化订阅）
  state/sessionRestore.ts  # 会话恢复身份判定（纯函数）
  components/SliceView.tsx # 正交切面视图（vtk.js 渲染 + Canvas 叠加交互，按侧实例化）
scripts/generate-sample.mjs         # 合成岩芯样例生成器
scripts/generate-compare-samples.mjs # 双体积比较样例对生成器
e2e/smoke.mjs              # 单体积冒烟 E2E
e2e/compare.mjs            # 双体积比较验收 E2E
```
